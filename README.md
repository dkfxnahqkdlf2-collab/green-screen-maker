# 🎬 크로마키 배경 제거기

영상 파일을 드래그앤드롭하면 AI가 자동으로 배경을 제거하고  
**CapCut 크로마키에서 바로 쓸 수 있는 초록 배경 MP4**로 변환해줍니다.

![미리보기](preview.png)

---

## ✅ 특징

- 🖱️ **드래그앤드롭** — 파일 창에서 영상을 그냥 끌어다 놓으면 끝
- 🤖 **AI 배경 제거** — rembg u2net 모델, 복잡한 배경도 처리
- ⚡ **GPU 자동 가속** — NVIDIA / AMD / 인텔 GPU 자동 감지 (DirectML)
- 🎨 **초록 배경 출력** — CapCut 무료판 크로마키에 최적화
- 📦 **일괄 변환** — 여러 파일 한 번에 처리

---

## 📋 요구 사항

- Windows 10 / 11 (64bit)
- **Python 3.10 이상** → [다운로드](https://www.python.org/downloads/)  
  ⚠️ 설치 시 **"Add Python to PATH"** 반드시 체크!

---

## 🚀 설치 및 실행

### 1단계 — 다운로드
오른쪽 상단 **Code → Download ZIP** 클릭 후 압축 해제

### 2단계 — 설치 (최초 1회)
```
install.bat  더블클릭
```
> 패키지 설치에 수 분 소요됩니다.

### 3단계 — 실행
```
실행.bat  더블클릭
```
> 최초 실행 시 AI 모델 다운로드(약 170MB)로 1분 정도 걸립니다.  
> 이후부터는 바로 실행됩니다.

---

## 🎬 사용 방법

1. `실행.bat` 더블클릭으로 프로그램 실행
2. 영상 파일을 프로그램 창에 **드래그앤드롭** (또는 `📁 파일 선택` 버튼)
3. `▶ 변환 시작` 클릭
4. 완료 후 `📂 결과 폴더 열기`로 결과 확인

**출력 파일 위치:** 바탕화면 `green_output` 폴더 (변경 가능)

---

## 🎨 CapCut 크로마키 적용법

1. CapCut에서 `green_파일명.mp4` 임포트
2. 클립 선택 → **크로마키** 탭 클릭
3. 색상 피커로 ���록 배경 클릭
4. 강도 조절 후 완료

## 🛠️ 지원 형식

| 입력 | 출력 |
|------|------|
| mp4, mov, avi, mkv, wmv, webm, flv | mp4 (H.264, 초록 배경) |

## ⚙️ GPU 가속

| 환경 | 속도 |
|------|------|
| NVIDIA GPU (DirectML) | ~25 fps |
| AMD / 인텔 GPU (DirectML) | ~10–15 fps |
| CPU만 있는 경우 | ~2–3 fps |

## ❓ 자주 묻는 질문

**Q. 창이 한참 멈춰 있어요**  
A. 첫 실행 시 AI 모델을 다운로드합니다 (약 170MB). 기다려주세요.

**Q. 캐릭터가 일부 지워져요**  
A. 배경이 캐릭터와 색이 너무 비슷하거나, 강한 빛/홀로그램 효과가 있을 때 발생합니다. AI 한계로 완벽하지 않을 수 있습니다.

**Q. GPU가 없어도 되나요?**  
A. 됩니다. CPU로도 동작하지만 느립니다.
